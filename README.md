# Stock Scan AI
Android wrapper for the Stock Scan AI Hatchable app.

## APK
GitHub Actions builds a debug APK on every push. Open **Actions → Build Stock Scan AI APK → latest run → Artifacts → Stock-Scan-AI-debug-apk**.

Current app loads: https://stock-scan-ai.hatchable.site

> Paper/virtual trading proof mode. Live NSE market data is not connected yet.
